# Trazabilidad

Las tres matrices que exige [`CLAUDE.md` §10](../../CLAUDE.md). Se actualizan en cada hito
(§13) y son lo que permite responder, sin buscar entre carpetas, dos preguntas:

- **¿Queda algún ítem del sílabo sin artefacto?** → [Matriz A](matriz-a-temario.md)
- **¿Queda algún requerimiento sin servicio responsable?** → [Matriz B](matriz-b-requerimientos.md)

| Matriz | Relaciona | Para qué sirve |
| :--- | :--- | :--- |
| [A](matriz-a-temario.md) | Temario ↔ entregable | Ningún ítem del sílabo queda sin cubrir |
| [B](matriz-b-requerimientos.md) | RF/RNF ↔ servicio | Ningún requerimiento queda huérfano |
| [C](matriz-c-principios.md) | Principios de diseño ↔ servicio | Los 8 principios, verificados servicio por servicio |

**Las tres declaran lo que falta.** Una matriz en la que todo sale en verde no se ha revisado
de verdad: se ha rellenado.
